Infinitunes Android: Material 3 Expressive

Reference mockup for the Android app (360dp phone, dark Material You scheme). Spec: spec.md. Compact, YouTube Music density: 40dp buttons (48dp targets), 56dp rows, 32dp chips, emphasized type for hierarchy only. Expressive layer: shape (8/12/16/28 corners, full buttons that morph to 8 while pressed, a play button that is a rounded square paused and a circle playing), connected button groups, segmented lists, spring motion.
