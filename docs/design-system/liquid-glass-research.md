Audience: web implementers (WP2 glass engine). Mockup code wins over every claim here: `design-mockups/final/glass.css`,
`glass.js`, `glass-spec.md`. Sources were fetched on 2026-10-10. Apple's HIG "Materials" and "Liquid Glass" pages are

## 1. The three layers and their web mapping

css-tricks names them highlight, shadow, illumination; Apple's session frames the material as lensing plus adaptivity.
Working model (same as glass-spec.md section 1):

| Layer                 | What Apple does                                                                                  | Web mapping                                                                                                                                                                                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Lens / refraction     | "bends, shapes, and concentrates light in real time"; gives definition while staying transparent | SVG `feImage` displacement map + `feDisplacementMap` inside `backdrop-filter: url(#id) blur() saturate()`. Map = rounded-rect SDF, convex squircle bezel, Snell's law (ior 1.5), RG channels, 128 = neutral, `color-interpolation-filters="sRGB"`. Chromium only. |
| Highlight / specular  | light casts along the edge and moves with interaction                                            | CSS: 1px masked `::before` ring, gradient angle `--g-light` (pointer driven) plus inset box-shadows. Lens path: baked Blinn-Phong specular `feImage` blended `screen`.                                                                                            |
| Shadow / illumination | shadow adapts to content; glass "energizes with light" when touched                              | Size-scaled drop shadow, top-down wash, radial press glow `::after` at `--g-px/--g-py`.                                                                                                                                                                           |

Browser limits (kube.io: "Only Chrome currently supports using SVG filters as `backdrop-filter`"): Safari and Firefox parse
`url()` there and render nothing, so `CSS.supports` alone lies; gate on Chromium via `navigator.userAgentData.brands`.
Everything else keeps tint, blur, saturate, rim, shadow (the "frosted fallback"). Maps do not resize with the element, so
filters are keyed per w x h x radius x size; changing size rebuilds the map (expensive), animating `scale` is cheap.
`backdrop-filter` only samples inside the border box, so offsets must point inward (mockup does).

## 2. Variants

- Regular: default, adapts to backdrop, any size, any content. "The variants should never be mixed" (219).
- Clear: no adaptive behaviour; needs a dimming layer. Use only over media-rich content, when dimming does not hurt the
  content, and the foreground is bold and bright (219). Mockup: hero caption, Now Playing top buttons, toolbar capsules over an
  artwork header. Mockup dim = `0.16 + 0.44 * --g-art-l`, white text, text-shadow.
- Tinted: colour mapped to backdrop brightness, only "to bring emphasis to primary elements and actions" (219). Mockup:
  Log in, Now Playing play/pause. Tint alpha `0.7 + --glass-tint`, text `--on-accent`, 3:1 target (UI component).
- The user-level Variant setting only re-skins `s` and `m` regular surfaces; `l` and `xl` stay Regular for legibility.

## 3. Placement

Glass is the functional layer floating above content, "not directly on content" (356). Allowed (navigation layer): sidebar,
toolbar capsules, tab bar, player, queue pane, menus, popovers, dialogs, sheets, toasts, segmented-control droplet, command
palette. Forbidden: content cards, table rows, rank badges, prose, auth artwork panel, lyric/queue lists (use `color-mix(bg 40%)`).
No glass on glass: controls inside glass get a `rgb(127 127 127 / .14)` hover and the spring press, never a backdrop filter
(mockup: `[data-glass]:not(#tabbar) .seg > .lg-sel.lifted`). Apply the material to the control itself, not inner views (356).
Modal tasks: pair glass with a dimming scrim (356).

## 4. Geometry, edges, legibility

- Concentric radii: inner radius = outer radius minus inset (356). Mockup: player `--r-lg + 4px`, artwork `max(4px, r - 10px)`;
  sidebar and wide queue `--r-lg + 6px` at a 0.5rem inset; capsules 999px on phones (artwork becomes a circle).
- Scroll edge effect replaces dividers: a blur and fade of content under floating UI, one per view, soft by default, hard for
  dense or phone bottoms; remove any extra bar background (356, 323). Mockup: `.bar::before/::after` masks plus `.lg-edge-bottom`.
- Thickness: bigger surfaces are thicker: more blur, more tint, deeper shadow, weaker lens (219). Mockup size table s/m/l/xl.
- Vibrancy and AA: secondary text on glass is heavier (500) and 88% light / 94% dark alpha (66% fails). Text-bearing `m`
  surfaces use backdrop `contrast(.6|.5)` and tint floor so WCAG AA (4.5:1) holds over black/white extremes (measured, spec
  section 5). `s` icon-led surfaces are only guaranteed 3:1. Clear glass is AA only near the sampled mean luminance.
  css-tricks warns contrast varies with backdrop: test over bright and busy imagery, not polished screenshots.

## 5. Motion

- Springs, interruptible: app `spring({from,to,velocity,response,damping})` (critically damped default, retargetable, velocity
  handoff). Press in response .30 damping 1, release damping .55 (self gel) or .75 (child). Selection slide .38/.82, drag
  release .35/.80 with `project(v, .99)`, rubber band `o*d*.55/(d+.55*|o|)`.
- Materialize (219: "instead of fading, objects materialize by modulating the light bending"): opacity 0, scale .92, blur
  10px to 0 over .34s `cubic-bezier(.32,1.18,.5,1)`, and lens `scale` ramps 0 to 1 over 320ms ease-out cubic.
- Press gel: capped growth (child `1 + min(.08, 6/width)`, self `1.06 x 1.04`), glow from the touch point.
- Tab bar minimize on scroll (323 `tabBarMinimizeBehavior(.onScrollDown)`; not in 219/356): after 48px accumulated down past
  y 40; expand after 24px up, y < 40, or tap. Player slides into the freed row.
- Queue morph from the player below 1440px: clip-path + translate + blur, .46s.

## 6. Accessibility overrides

Apple: Reduce Transparency makes glass frostier, Increase Contrast goes near black/white with a border, Reduce Motion
removes elastic effects (219). Mockup: `prefers-reduced-transparency` lens off, `--g-a .86`, clear dim .62/tint .04, ambient x0.5;
`prefers-contrast: more` surface tint at .97, no backdrop-filter, no rim, 1.5px text-mix border; `prefers-reduced-motion` and
`html.reduce-motion` fade .2s, no queue morph, tab bar/player transition opacity only. Forced colors: the mockup has NO
rule. Required addition for WP2: under `@media (forced-colors: active)` set `background: Canvas`, `color: CanvasText`, no
backdrop-filter, `forced-color-adjust: auto`, `border: 1px solid CanvasText`, hide `::before`/`::after`.

### Values that differ between app and mockup

- Lens scale: app `strength * k * 18`; mockup `2 * refraction * strength * k` (default 60 for `s`, +-30px).
- Spec slope: app fixed `1`; mockup `min(1.5, spec * .8)`.
- `--ambient` effective default: app .22 (light) / .32 (dark) from `globals.css`; mockup .62 (glass.css `#ambient` overrides style.css .22/.32).
- Press glow px/py: app percentages; mockup pixels from host origin. `--g-press` jumps; mockup springs.
- Materialize ramp: app on every surface; mockup only menu, dialog, palette, toast, and only when `!reduced()`.
- Filter id counter starts at 1 (mockup 0); harmless.
- `xl` lens: app hook does not suppress it; mockup never lenses `xl`.
- Glass level and variant transport: app data attributes on `<html>`; mockup classes (`glass-off`, `lg-v-*`, `lg-accent-tint`, `lg-capable`, `lg-lens`, `reduce-motion`, `no-ambient`).
- Sizes, blur factors, tint adds, shadows, rim stops, clear dim, tinted alpha, contrast values: identical (S is a copy).
- Base UI note: Base UI popups animate with `data-starting-style` / `data-ending-style`, not mount order; hook the materialize keyframes to those, and confirm exact attribute names in the installed package before coding.

## 8. Implementation checklist for WP2

1. Fix section 7 rows 13, 14, 17, 28 first: without them the lens never runs, and the document root is matched as a glass surface.
2. Port, in order: lens scale/spec fixes (10), spring helper (30), press (3), pointer light (1), sampler (5), selector (4), tab-min (6), scroll edge (7), ambient (15).
3. Gate every motion path on `prefers-reduced-motion` and `data-motion="reduced"`; gate every lens path on capability, reduced transparency, contrast, solid.
4. Test pure logic (SDF, maps, scale maths, tab-min thresholds, sampler vivid-set, capability gate) with bun tests; DOM tests with react-dom/client + act.
