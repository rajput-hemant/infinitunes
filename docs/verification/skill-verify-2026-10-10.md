## Observations, not fixed

- At 640x400 (200% on a 1280x800 window) the profile header, tab strip, player bar and bottom nav fill most of the height; content is reachable by scrolling but only a sliver is visible between the fixed bars. Not judged a defect.
- Row-level Like buttons are hidden (zero size) below the `md` breakpoint; only the header Like and the row menu remain.
- A T3 `preview_*` host dropped twice during the run ("No preview automation host", then `chrome-error://`), because the dev server had died (killed by something outside this task); the session cookie was gone after the restart. The skill documents the restart.

## Defects

| Commit        | Subject                                               | Test                                                                                                                                                                                                                             |

| see `git log` | fix(web): copy auth request from url, method and body | `tests/client-ip.test.ts` (10 pass, includes the body-kept case); the original failure only reproduces inside the Next runtime on Node 24.21, so there is no unit reproduction. Live: 500 before, 200 after, then a form signup. |

`new Request(request, { headers })` in `withTrustedClientIp` (`apps/web/lib/client-ip.ts`) threw `Cannot read private member #state from an object whose class did not declare it` for the `NextRequest` the route handler receives, so every `/api/auth/*` call returned 500 under `next dev` (signup, login, passkey list). A bare `new Request(nextRequest, ...)` does not fail under Bun or plain Node, so the cause is the Next runtime. Production on Vercel was not checked.
