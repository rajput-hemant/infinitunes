# @infinitunes/ui

Web-only UI component library for Infinitunes built with Tailwind CSS, Base UI, and Lucide React.

> **Important:** This package is web-only due to DOM, CSS, and web-specific dependencies (such as `@base-ui/react`, `next-themes`, and DOM APIs). It must not be imported by a future React Native or Expo mobile application. Cross-platform primitives or mobile UI components belong in a separate package.
